# Code de conduite

## Ce qu'on attend

Ce projet est né pour une personne de soixante ans qui voulait suivre son poids
sans être jugée par une application. Cette intention vaut aussi pour les échanges
autour du code : on s'y adresse à des personnes, jamais à des dossiers.

Concrètement :

- **Supposez la bonne foi.** Une question naïve est une question, pas une perte de
  temps. Quelqu'un qui n'a jamais contribué à un projet libre est exactement le
  genre de personne pour qui celui-ci est écrit.
- **Critiquez le code, jamais la personne.** « Cette fonction ne gère pas le cas
  où la valeur manque » est utile ; « tu n'as pas réfléchi » ne l'est pas.
- **Expliquez vos refus.** Une proposition écartée mérite la raison qui l'écarte.
  La [charte](CHARTE.md) en fournit la plupart.
- **Écrivez en français ou en anglais**, au choix. Le code et les commentaires
  sont en français ; personne n'est tenu de l'être dans une discussion.

## Ce qui n'a pas sa place

Le harcèlement, les propos discriminatoires, les remarques sur l'apparence ou le
poids de qui que ce soit, la publication d'informations privées, et toute forme
d'intimidation.

Le sujet de cette application la rend particulièrement concernée par un point :
**aucune remarque sur le corps d'une personne**, contributrice ou utilisatrice,
n'est acceptable ici, y compris présentée comme un conseil de santé ou une
plaisanterie.

## Signaler

Écrire à <tom.cavaignac39@gmail.com>. Un signalement est traité confidentiellement.

Les suites possibles vont du rappel privé au retrait de l'accès au dépôt, selon
la gravité et la répétition. La personne qui signale n'a pas à justifier qu'elle
a été suffisamment blessée pour avoir le droit de le dire.

## Portée

Ce code s'applique aux espaces du projet — dépôt, tickets, propositions de
modification — et aux échanges publics où quelqu'un représente le projet.
